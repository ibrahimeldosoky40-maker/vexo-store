# Vexo Store — Handover

Headless e-commerce storefront for **Vexo Store** (phone cases, smart watch bands, chargers, laptop sleeves).
Primary language: English. Arabic (`/ar`, RTL) is wired and ready.

## 1. Tech stack
- **Next.js 16.3.8** (App Router, Turbopack), **React 19**, **TypeScript**
- **Tailwind CSS v4** (design tokens in `src/app/globals.css`)
- **Shopify Storefront API** via `graphql-request` (API version `2026-07`)
- `lucide-react` icons (v1: no brand icons, socials are inline SVGs), `clsx`
- i18n: custom dictionaries (`src/dictionaries/en.json`, `ar.json`), locale routing in `src/proxy.ts`
  (Next 16 renamed `middleware` to `proxy`)
- Brand assets generated by `scripts/generate-brand-assets.py` (Pillow, scipy, numpy)

## 2. Environment variables (`.env.local`, NOT committed; see `.env.example`)
```
NEXT_PUBLIC_SHOPIFY_STORE_DOMAIN=vexo-store-test.myshopify.com
NEXT_PUBLIC_SHOPIFY_STOREFRONT_ACCESS_TOKEN=<storefront token>
# optional
NEXT_PUBLIC_FREE_SHIPPING_THRESHOLD=50
SHOPIFY_MENU_HANDLE=main-menu
```
Set the same variables in Vercel (Project Settings -> Environment Variables).
